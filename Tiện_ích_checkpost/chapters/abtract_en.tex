\addcontentsline{toc}{chapter}{Abstract}
\begin{small}

In the context of rapid digital transformation, phishing attacks remain a prevalent cybersecurity risk. Malicious actors continuously adapt their strategies using concealment techniques such as URL shortening and Typosquatting, rendering static defense systems ineffective. A robust client-side protection solution is required to analyze and issue immediate warnings against suspicious URLs. The CheckPost project was developed to address this challenge by building a browser extension (Manifest V3) powered by Artificial Intelligence. Notably, this research successfully mitigates Data Leakage—a critical flaw often found in cybersecurity machine learning—and optimizes an XGBoost algorithm combined with a Heuristic engine (Levenshtein distance) for multi-layer URL analysis. This approach enables the system to achieve predictions with a False Positive Rate approaching 0\%, alongside Explainable AI capabilities (SHAP), effectively preventing zero-day attacks. Experimental results confirm that the extension operates reliably with extremely low latency, ensuring user information security without degrading web browsing performance.

\textbf{Keywords}: Cyber Security, Browser Extension, Phishing, XGBoost, Explainable AI, Data Leakage, Manifest V3
